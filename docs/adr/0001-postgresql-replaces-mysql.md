# PostgreSQL replaces MySQL (single DB, not DB-agnostic)

The inherited template was MySQL-backed. We convert it to be **PostgreSQL-only** — removing the MySQL driver, `flyway-mysql`, and all MySQL config rather than making the template support both engines via configuration. Single-DB keeps the migration and test surface honest and unambiguous (a "DB-agnostic" template doubles the migration/test matrix forever and one path silently rots). The repo name (`oauth-postgresql`) and the stated mission ("just a conversion") both point here. Consequence: enum columns become `VARCHAR` (entities use `@Enumerated(EnumType.STRING)`), and `V1__init_schema.sql` is rewritten as Postgres DDL validated against the JPA entities under `ddl-auto: validate`. If a future project needs MySQL, it branches from upstream rather than this template carrying both.
